lists the third-party software compiled into it and the third-party artwork in
the app, with the copyright notices and license texts that those licenses
require a binary distribution to include.

`LICENSE` and `NOTICE` at https://github.com/nolanmak/FlyOnTheWall.

## App icon and web UI favicon

The app icon (`packaging/AppIcon.svg`, and `packaging/AppIcon.icns`, which the
app carries as `Contents/Resources/AppIcon.icns`) and the web UI favicon
(`crates/fotw-web/ui/favicon.svg`, embedded in fotwd) are derived from "Fly"
by Delapouite, https://game-icons.net/1x1/delapouite/fly.html, licensed under
CC BY 3.0, https://creativecommons.org/licenses/by/3.0/.

Changes from the original: the fly is recolored green (#0cd420). AppIcon.svg
sets it on a dark rounded-square tile (#171A2B), and AppIcon.icns is rendered
from AppIcon.svg. favicon.svg has no background. The outline is not redrawn:
its path is the copy in Iconify's game-icons set, which encodes the original
path more compactly and rounds some values but keeps every segment's end
point.

## C libraries compiled into fotwd

Three crates compile C libraries from source and link them statically into
fotwd. A crate's manifest declares the license of the crate, not of the C code
it carries, so these libraries are listed here separately.

## Rust crates

These are the crates compiled into fotwd for aarch64-apple-darwin and
x86_64-apple-darwin: everything fotwd reaches through normal dependencies,
apart from FlyOnTheWall's own crates. Build and dev dependencies do not end up
in the binary and are not listed. Procedural macros and the crates they use
are listed even though they run only at compile time, because Cargo records
them as normal dependencies.

A crate offered under a choice of licenses is listed under one of them. When a
crate's package does not include the text of its license, the standard SPDX
text of that license is shown. Each distinct license text appears once, after
the list of crates that use it.
